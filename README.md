# Kismet

Portfolio site for Andrew Loehr, live at [kismet-ux.com](https://kismet-ux.com).

React, TypeScript, Vite, and SCSS modules, deployed on Netlify.

## Scripts

- `yarn start` runs the dev server on port 3000
- `yarn build` typechecks and builds to `build/`
- `yarn lint` and `yarn lint:fix`
- `yarn format` and `yarn format:check` run Prettier, which also sorts stylesheet properties
